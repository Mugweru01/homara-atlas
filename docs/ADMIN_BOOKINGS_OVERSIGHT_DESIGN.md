# Admin Short Stay Bookings - Oversight Dashboard Design

## 🎯 Purpose
This is an **admin oversight dashboard** to monitor and ensure proper management of all BNB bookings across the platform. Landlords have their own dashboard for managing their properties - this is the admin's view to ensure compliance, track issues, and maintain platform quality.

## 📊 Key Features

### 1. **Oversight Dashboard**
- Platform-wide booking overview
- Real-time monitoring of all bookings
- Alerts for issues requiring attention
- Compliance status indicators

### 2. **Refund Management**
- Track all refund requests
- Refund approval workflow
- Refund history and patterns
- Dispute-related refunds
- Refund analytics

### 3. **Cancellation Tracking**
- Cancellation reasons analysis
- Cancellation patterns by landlord/property
- Policy compliance checks
- Cancellation rate monitoring
- Refund processing for cancellations

### 4. **Compliance & Quality Control**
- Policy violation detection
- Booking quality metrics
- Landlord performance monitoring
- Guest satisfaction tracking
- Automated alerts for issues

### 5. **Financial Oversight**
- Revenue tracking per landlord
- Commission/fee tracking
- Payment disputes
- Financial reconciliation
- Revenue trends

### 6. **Audit Trail**
- Complete booking history
- Admin actions log
- Status change tracking
- Refund/cancellation audit
- Compliance audit

## 🏗️ Page Structure

### Main Tabs:
1. **Overview** - Dashboard with KPIs and alerts
2. **All Bookings** - Complete booking list with filters
3. **Refunds** - Refund management and tracking
4. **Cancellations** - Cancellation analysis and tracking
5. **Compliance** - Policy violations and quality issues
6. **Landlord Performance** - Landlord metrics and oversight
7. **Disputes** - Booking-related disputes

### Key Metrics to Display:
- Total bookings (all landlords)
- Active bookings
- Pending refunds
- Cancellation rate
- Compliance violations
- Dispute count
- Revenue (platform-wide)
- Average booking value
- Refund rate
- Cancellation rate by reason

## 🔍 Admin Actions Available:
- Approve/reject refunds
- Override booking status
- Issue warnings to landlords
- Flag problematic bookings
- Process refunds manually
- Escalate disputes
- View complete audit trail
- Export reports
